Reflection: How Web Architecture Evolved

1. Static pages and graphical browsers (1990s)
As graphical browsers such as Mosaic made images and richer pages more accessible, web servers had to deliver more types of files. This increased the importance of efficient HTTP delivery and sufficient network bandwidth.

2. JavaScript and dynamic server responses (mid 1990s)
JavaScript made it possible to validate forms and respond to user actions in the browser. CGI and later persistent server workers allowed the server to process submitted data and generate dynamic responses. Together, these technologies helped turn websites into interactive applications.

3. AJAX and efficient backend APIs (2000s)
AJAX allowed browsers to request data without reloading an entire page. This created greater demand for efficient backend endpoints, structured responses, and reliable handling of many concurrent requests.

4. Single page applications and modern server rendering (2010s to present)
Frontend frameworks moved more interface logic into the browser. However, large JavaScript bundles and slower initial rendering encouraged renewed interest in server side rendering, static generation, and edge delivery. Modern architectures balance work between the browser and server rather than relying entirely on one.
